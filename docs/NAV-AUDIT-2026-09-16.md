## 3. 欠陥一覧（重要度順）

### 🔴 D-01 オンボーディングが片道切符（唯一の出口が `replace`）

- `app/onboarding.tsx` に `<Stack.Screen>` が無い → ルートの `headerShown:false` のまま＝**ヘッダーも戻るボタンも出ない**
- 画面内の唯一の離脱導線は `onboarding.tsx:138`「あとで設定」→ `done()` → `onboarding.tsx:80` **`router.replace('/(tabs)/log')`**
- 入口は `settings.tsx:939-941`「初期設定をやり直す」→ `push('/onboarding')`。
  コード中のコメントは「**replace ではなく push なので、やめても設定に戻れる**」と書いてあるが、
  **やめる操作そのものが replace** なので、タップで設定に戻る道は存在しない。
- さらに `__tests__/onboardingReentry.test.ts` は「settings が push で開くこと」だけを検査しており、
  **この穴を通してしまう**（偽の安心を与えているテスト）。
- **ユーザーから見て:** 設定を見直そうとウィザードを開き、「やっぱりいい」と思って「あとで設定」を押すと、
  設定画面ごと消えて食事タブに放り出される。設定に戻るにはタブを渡り歩いて概要→設定と入り直す。
- **直し方:**
  1. `onboarding.tsx` に `<Stack.Screen options={{ headerShown: true, title: t('初期設定'), headerBackTitle: t('戻る') }} />` を足す。
  2. `done()` を「初回（bl-onboard-done が未設定）なら `replace('/(tabs)/log')`、再実行なら `router.back()`」に分岐させる。
  3. `onboarding.tsx:147` の「あとで**⚙**からいつでも変更できます」は **2026-09-04 に廃止された⚙**を指している。
     「あとで**概要タブの「設定」**から変更できます」に。
  4. `onboarding.tsx:179` の「あとで「**設定→体重の目標**」から」も実在しない経路名（設定の行名は「目標」）。

### 🔴 D-02 タブへの遷移を `push` で書いている4か所 — 履歴が二重・無限に積まれる

- `weekly-review.tsx:313` `push('/(tabs)/changes?open=week')`
- `NotificationCenter.tsx:39` `push(todo.route)`（`/log` `/training` `/changes`・`lib/todos.ts:12`）
- `coach.tsx:284` `push('/(tabs)/log')`
- `training.tsx:669` `push('/(tabs)/changes')`

対して `PlusEntry.tsx:123-131` と `GuideTour.tsx:150-185` は **`router.navigate`** を使っている＝同一リポジトリ内に正解の前例がある。

- **一番悪いのが週次レビューの往復:**
  概要「週のふりかえり」→ `push('/weekly-review')` → 「くわしく見る」→ `push('/(tabs)/changes?open=week')`
  → 「‹ 概要」で一覧に戻る → もう一度「週のふりかえり」→ `push('/weekly-review')` …
  スタックが `[(tabs), weekly-review, (tabs), weekly-review, …]` と**往復のたびに2段ずつ伸び続ける**。
- **通知センターはさらに悪い:** 通知センターは `/settings` の中のシート。そこから `push('/log')` すると

## 4. あるべき階層構造（現実的な案）

全面作り直しはしない。**「タブの中で完結するもの」と「タブの外に住むもの」の線を1本引き直す**だけ。

### 4-1 線の引き方

```
タブの中（＝タブ内詳細・戻りは「‹ 概要」）
    データを“見る”もの: 体の記録 / バイタル / 生理周期 / 体の写真 / リーンバルク /
                        サイクル比較 / 食べ方の分析 / 運動の量 / 筋トレの成長 / 歩数・睡眠
    ＋ あなたの法則・栄養ランキング・週のふりかえり も **ここへ引き込む**（D-05 案B）
       （どれも「記録から作られた読み物」で、設定でもアカウントでもない）

タブの外（＝スタック画面・戻りは「‹ 前画面名」）
    アプリを“変える”もの: 設定 / プラン(paywall) / 初期設定 / ログイン
    記録を“作る”もの:     筋トレを記録（lift-session）
    本人の記録を“讃える”もの: 実績
```

案Bが重すぎるなら **D-05 案A（外部リンク印を付ける）** で妥協。線は引かないが、
「押した結果の種類が違う」ことは見た目で予告できる。

### 4-2 概要タブの「設定ブロック」の再編（親の修正と整合させる）

熊田さん指摘のとおり「設定ブロックに設定以外が多い」。本監査の結論も同じで、**中身が3種類混ざっている**:

| いまの行 | 実体 | 提案 |
|---|---|---|
| 目標設定 | 設定（/settings のシート） | **「設定」節に残す**。名前は「**目標**」に統一（D-17） |
| 実績 | 本人の成果を見るページ | **概要の一番上・独立した1行**へ（設定節から出す）。`settings.tsx:664` の重複行は削除 |
| 通知センター | いまやることの通知 | **TabHeader の右にベルアイコン＋バッジ**として出す（4タブ共通で使える）。設定節から出す |
| 設定 | マイページ | **「設定」節に残す**。名前を「設定」に統一（着地見出しも変える・D-09） |

→ 節の名前と中身が一致し、節の中は「目標」「設定」の2行だけになる。熊田さんの
「設定が下にあるのが違和感」も、2行なら「目標 → 設定」の順が自然（抽象度の低い順）。

### 4-3 戻るボタンの規約（1本に決める）

2026年の iOS HIG は「戻るボタンは前の画面のタイトル」、Material 3 は predictive back で
「戻った先のプレビュー」を出す。どちらも **行き先を見せる** 方向。いま概要タブの「‹ 概要」だけが
これに合っており、スタック8画面の `headerBackTitle: t('戻る')` が例外。

**規約案:**
1. 各スタック画面は `title` を必ず持つ（`lift-session.tsx` だけがすでに正しい）。
2. `headerBackTitle` の**固定指定をやめる** → iOS が自動で前画面のタイトルを出す。
   前画面がタブの場合は `(tabs)` に `title` が無いので、`(tabs)/_layout.tsx` 側か
   各タブの `Stack.Screen` で `title` を与える（食事／運動／相談／概要）。
3. タイトルが長すぎて省略される画面だけ、例外的に `headerBackButtonDisplayMode: 'minimal'`（矢印だけ）にする。
   **`'戻る'` という語はアプリから消す。**
4. 概要タブ内詳細の「‹ 概要」はそのまま（規約に合っている）。ただし D-18 のとおり sticky にする。

### 4-4 シートと画面の使い分け

| 操作の重さ | 出し方 | 閉じ方 |
|---|---|---|
| 1つの値を選ぶ・読むだけ（言語・テーマ・記事・表） | pageSheet | 右上 **Xアイコン** |
| 複数項目を編集して確定する（プロフィール・目標・食事の制約・マイ食品） | pageSheet | 右上 **完了**（＋変更があれば破棄確認） |
| 別の文脈へ移る・URLで指せる必要がある（設定・実績・プラン・法則・週次・栄養） | **push（スタック画面）** | ネイティブ戻る |
| その場の一時的な選択（ダイアル・カレンダー・時刻） | transparent 中央ダイアログ | **キャンセル**＋背景タップ |

これに照らすと現状の逸脱は:
- **「目標」だけがシートなのに `?open=goal` で URL から指されている**（＝画面の資格があるのにシートで実装されている）。
  熊田さんの「目標設定だけ下からにょきっと」はここが本質。
  → **`/goal-settings` というスタック画面に昇格**させ、`GoalPanel mode="hub"` をそこに置く。
    `/settings?open=goal` は `/goal-settings` への互換リダイレクトにする。
    概要の「目標」行も、相談タブの「設定で細かく調整」も、log の残量タップも、全部そこへ1段で着く。
    `GoalSummaryCard` はシートをやめてその画面へ push する（D-17 も同時に解消）。
- `training.tsx:702/733` の2シートだけ閉じ方が素の `×` 文字（D-16）。
